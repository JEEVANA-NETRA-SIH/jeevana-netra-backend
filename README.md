# Jeevana Netra MATLAB Backend

MATLAB-based backend for the Jeevana Netra diabetic retinopathy screening system.

## Structure

- matlab_backend/ - MATLAB API, prediction, preprocessing, explanation, and report-generation source code.

## Large Runtime Artifacts

The trained model files and compiled MATLAB deployment archive are intentionally excluded from the normal Git repository because of their large file sizes.

Deployment artifacts will be handled separately during the deployment phase.
